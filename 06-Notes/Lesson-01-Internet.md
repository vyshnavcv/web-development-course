# 1. Internet

Definition:
The Internet is a global network of interconnected computers that communicate using standard protocols.

Key Points:
- Connects billions of devices.
- Transfers data worldwide.
- Supports many services like the Web, Email, Gaming, Video Calls, etc.

Example:
Just like roads connect cities, the Internet connects computers.

---

# 2. World Wide Web (WWW)

Definition:
The World Wide Web is a service that runs on the Internet and allows users to access websites.

Difference:

Internet
- Infrastructure (network)

WWW
- Collection of websites accessed through browsers.

Important:
The Internet existed before the Web.

---

# 3. Client

Definition:
A client is a device or application that requests information.

Examples:
- Google Chrome
- Microsoft Edge
- Firefox

The browser is usually the client.

---

# 4. Server

Definition:
A server is a computer that stores websites and responds to client requests.

Responsibilities:
- Store website files.
- Process requests.
- Send responses.

---

# 5. Browser

Definition:
A browser is software that retrieves and displays web pages.

Examples:
- Chrome
- Edge
- Firefox

Browsers understand:
- HTML
- CSS
- JavaScript

---

# 6. IP Address

Definition:
An IP (Internet Protocol) Address is a unique numerical address assigned to every device connected to a network.

Example:
142.250.xxx.xxx

Purpose:
Allows computers to locate each other.

Think of it as:
A house address for computers.

---

# 7. Domain Name

Definition:
A human-readable name that represents an IP address.

Example:

google.com

instead of

142.xxx.xxx.xxx

Advantages:
- Easy to remember.
- User-friendly.

---

# 8. DNS (Domain Name System)

Definition:
DNS converts domain names into IP addresses.

Example:

google.com

↓

142.xxx.xxx.xxx

Think of DNS as:
The Internet's phonebook.

---

# 9. HTTP

Full Form:
HyperText Transfer Protocol

Purpose:
Allows communication between browsers and servers.

Example:

Browser → GET Request

↓

Server → Response

HTTP is NOT encrypted.

---

# 10. HTTPS

Full Form:
HyperText Transfer Protocol Secure

Purpose:
Secure communication between browser and server.

Advantages:
- Encrypts data.
- Protects passwords.
- Protects personal information.
- Prevents many attacks.

Always prefer HTTPS websites.

---

# 11. HTML, CSS and JavaScript

HTML
Purpose:
Structure of a webpage.

Examples:
- Heading
- Paragraph
- Button
- Image

CSS
Purpose:
Styles the webpage.

Examples:
- Colors
- Fonts
- Layout
- Animations

JavaScript
Purpose:
Adds functionality and interactivity.

Examples:
- Button click
- Form validation
- Navigation menu

---

# Complete Website Request Flow

1. User enters google.com
2. Browser asks DNS for Google's IP address.
3. DNS returns the IP address.
4. Browser connects to Google's server.
5. Browser sends an HTTP/HTTPS request.
6. Server responds with:
   - HTML
   - CSS
   - JavaScript
   - Images
7. Browser renders the webpage.
8. User sees the website.

# Summary

- WWW is a service running on the Internet.

- IP addresses identify devices.
